Project Scope:

Provides an online platform for gym membership registration and management.
Allows users to select membership plans and payment methods.
Stores and manages member details using a database.

Objective:

To simplify and automate the gym membership registration process.
To reduce manual record keeping and provide an easy-to-use interface.
